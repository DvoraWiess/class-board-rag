# בוט RAG למלון צוף הכרמל

בוט שעונה על שאלות של אורחים על מלון בחיפה: חדרים, מחירים ועונות, אוכל, שבת, משפחות, שירותים, נגישות, הנחות ונהלים.
הבוט עונה רק לפי המידע במאגר ומציג את הקבצים שהתשובה מבוססת עליהם.
**המלון וכל הנתונים בדויים.**

## התקנה והרצה (PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env; notepad .env   # להכניס OPENAI_API_KEY
python ingest.py                            # בניית האינדקס (בכל שינוי ב-data/)
streamlit run app.py
```

## ארכיטקטורה ובחירות טכנולוגיות
`data/*.md` → `ingest.py` (טעינה, חלוקה, Embeddings, Chroma) → `app.py` (חיפוש, תשובה, מקורות, ממשק).

- **LlamaIndex:** רכיבים מוכנים לכל שלב (`SimpleDirectoryReader`, `SentenceSplitter`, `VectorStoreIndex`), בלי לכתוב אותם לבד.
- **Chroma מקומי (cosine):** מאגר וקטורים שנשמר בתיקייה, בלי שרת ובלי חשבון.
- **`text-embedding-3-small`:** זול ומהיר, ותומך בעברית.
- **`gpt-4o-mini`, `temperature=0`:** מהיר וזול, ותשובות עקביות בלי "יצירתיות". אפשר להחליף את שני המודלים דרך `.env` (`LLM_MODEL`, `EMBED_MODEL`).
- **קובץ לכל נושא, `CHUNK_SIZE=1024`:** 27 קבצים קצרים (חדר, עונות, אוכל, שבת, חניה וכו'), וכל קובץ הוא קטע אחד. כך קטע לא מתפצל באמצע נושא.
- **`TOP_K=6`:** מספיק כדי לשלוף את החדר וגם את הנוהל הקשור, מתוך 27 קטעים.
- **ניסוח מחדש של שאלות המשך:** קריאה אחת ל-LLM הופכת "כמה הוא עולה?" לשאלה עצמאית לפי 6 ההודעות האחרונות. השאלה המנוסחת משמשת לחיפוש ולתשובה, כך שה-LLM שעונה לא צריך את ההיסטוריה.
- **Streamlit עם Streaming:** ממשק צ'אט קצר בקוד, והתשובה מופיעה תוך כדי כתיבה.
- **truststore:** בלעדיו החיבור ל-OpenAI נכשל מאחורי סינון אינטרנט (נטפרי).

## בעיות ותיקונים
הפירוט המלא ב-[docs/problems.md](docs/problems.md).
1. **בעיה:** קטעים של חדר בלי שם החדר, והתשובות ערבבו פרטים בין חדרים. **תיקון:** הגדלת ה-Chunk, כך שכל חדר הוא קטע אחד.
2. **בעיה:** השאלה הקודמת הסיטה את החיפוש לנושא הקודם. **תיקון:** חיפוש גם על השאלה הנוכחית לבד, ואיחוד התוצאות (הוחלף אחר כך בתיקון 6).
3. **בעיה:** בשאלות על "כל החדרים" נשלפו חדרים באקראי, ופעם אחת הומצא מחיר. **תיקון:** קובץ סיכום של כל החדרים, וכלל בפרומפט שכל מספר חייב להופיע בקטעים.
4. **בעיה:** שאלת המשך ("וכמה זה עולה?") לא מצאה את החדר שהוזכר רק בתשובה הקודמת. **תיקון:** חיפוש ההמשך כולל גם את התשובה הקודמת.
5. **בעיה:** המודל זרק מידע חלקי, והניח עונה מתוך ההיסטוריה. **תיקון:** כללים מפורשים בפרומפט.
6. **בעיה:** "כמה הוא עולה?" נענה "לא מצאתי", אף שהחדר הנכון נשלף. כלל מחודד בפרומפט לא הספיק. **תיקון:** ניסוח מחדש של שאלת ההמשך כשאלה עצמאית, וה-LLM שעונה כבר לא מקבל את ההיסטוריה.
7. **בעיה:** קובץ הסיכום התפצל לשני קטעים, וחדר חסר בתשובה. הגדלת הקטעים שברה שאלות אחרות. **תיקון:** קיצור הסיכום כך שייכנס בקטע אחד.
8. **בעיה:** כשבמאגר כתוב "אין מיני-בר", המודל ענה "לא מצאתי". **תיקון:** כלל בפרומפט ש"אין" או "אסור" הם תשובה.
9. **בעיה:** הניסוח מחדש החליף שאלה חדשה בשאלה הקודמת, ותיקון ראשון שלו הפסיק להשלים שאלות המשך. **תיקון:** ניסוח מאוזן ושתי דוגמאות בפרומפט.
10. **בעיה:** אחרי ההרחבה ל-27 קטעים, 4 קטעים לא הספיקו, וקובץ שערבב כמה נושאים לא נמצא. **תיקון:** `TOP_K=6`, וקובץ נפרד לחיות מחמד.
11. **בעיה:** ניסוח מתנגש בין שני קבצים ("אין ארוחת ערב במוצאי שבת") גרם לסירוב. **תיקון:** ניסוח מפורש בקובץ האוכל.
12. **בעיה:** תשובות שדרשו לחבר שני קבצים (למשל מועדון ילדים + עונות) יצאו חלקיות. **תיקון:** להכניס את העובדה החסרה לאותו קובץ.
