# לוח הודעות כיתתי עם בוט שאלות (RAG)

> **⚠️ נתוני דוגמה:** ההודעות ההתחלתיות במערכת (`data/sample_messages/`) **מומצאות** —
> שמות בדויים, כתובות בדומיין `example.com`, "בית ספר לדוגמה". הן משמשות לפיתוח ולבדיקות,
> וכל התוצאות בהגשה חושבו עליהן ועל הודעות שנוספו דרך המסך. אין במאגר מידע אישי אמיתי.

## מה המערכת עושה
לוח הודעות של קבוצת תלמידות: כל אחת יכולה להוסיף הודעה (שינוי במערכת, שיעורי בית, מבחן,
שאלה או תשובה), ובוט עונה על שאלות בשפה טבעית — רק לפי ההודעות, עם מקורות.

המערכת מטפלת במצבים שקשים ל-RAG פשוט:
- **עדכונים וביטולים** — הודעה חדשה ("המבחן נדחה") מחליפה הודעה קודמת.
- **סתירות** — שתי תלמידות שאומרות דברים שונים: הבוט מציג את שתי הגרסאות, עם שם ותאריך.
- **מידע חלקי** — הבוט אומר מה ידוע ומה חסר.
- **שרשורים** — תגובה ("אז ביום שני?") נקשרת להודעה שעליה ענו.

## טכנולוגיות
Python 3.13, LlamaIndex, Google Gemini (LLM + Embeddings), Chroma, Streamlit.
כל הגדרת המודלים נמצאת בפונקציה אחת: `setup_models()` ב-`src/config.py`. מעבר לספק אחר (למשל OpenAI)
= להחליף שם את שתי המחלקות (`GoogleGenAI`, `GoogleGenAIEmbedding`) ולהתקין את החבילות שלו,
ואז לבנות את האינדקס מחדש (ווקטורים של מודלים שונים לא ניתנים להשוואה — המערכת מזהה ועוצרת).

## התקנה (Windows / PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```
לפתוח את `.env` ולמלא ידנית את `GOOGLE_API_KEY` (מפתח חינמי מ-Google AI Studio).
אם המפתח חסר — האפליקציה מציגה הודעה בעברית עם שם המשתנה החסר.

## הרצה
```powershell
.\.venv\Scripts\streamlit.exe run app.py
```
נפתח דפדפן עם שתי לשוניות:
- **שאלות** — שואלים בשפה חופשית. התשובה מוצגת תוך כדי כתיבה, ומתחתיה המקורות (מי כתבה, מתי, איזו הודעה)
  וספירת טוקנים. השאלה והתשובה הקודמות משמשות רק כדי להבין שאלת המשך ("ומתי הוא?") לפני החיפוש.
- **הוספת הודעה** — שם, נושא, תוכן ו"בתגובה להודעה". ההודעה נכנסת לחיפוש מיד.

בהפעלה הראשונה: הודעות הדוגמה מועתקות ל-`data/messages/` ונכנסות לאינדקס (`chroma_db/`) — כמה שניות.
להתחלה מחדש: למחוק את `data/messages/` ואת `chroma_db/`.

## מקור הנתונים — מה נוסה ולמה
ההודעות נכנסות רק משני מקורות: **הטופס "הוספת הודעה"** ו**הודעות הדוגמה**. שניהם באותו פורמט JSON
(`src/messages.py`: `message_id`, `date`, `subject`, `from`, `in_reply_to`, `body`).

ייבוא מיילים **נוסה והוסר**, כדי לפשט את הקוד:
1. **IMAP מ-Gmail** — החיבור לשרת עבד, אבל Gmail דורש סיסמת אפליקציה, שדורשת אימות דו-שלבי,
   ו-Google חסמה את הפעלתו בחשבון. הקוד שמור ב-commit `6f423b5` (`src/fetch_emails.py`).
2. **ייבוא מקובץ Google Takeout** (`.mbox` / `.eml`) — עבד, אבל זו תמונת מצב קפואה, והמערכת צריכה מידע
   שמתעדכן כל יום. הוסר בפישוט הקוד; הקוד האחרון שמור ב-commit `abe8f7d` (`src/import_export.py`).

ניקוי ה-HTML, הציטוטים והחתימות (`src/clean.py`) נשאר — חלק מהודעות הדוגמה נכתבו כמו מיילים.

## כלים לפיתוח ולבדיקות
```powershell
.\.venv\Scripts\python.exe -m src.indexer [--rebuild]          # אינדוקס מצטבר / בנייה מחדש
.\.venv\Scripts\python.exe -m src.query "שאלה" --show-prompt    # תשובה + הפרומפט המלא שנשלח ל-LLM
.\.venv\Scripts\python.exe -m tests.inspect_retrieval "שאלה"    # מה נשלף ובאיזה ציון, בלי LLM
.\.venv\Scripts\python.exe -m tests.evaluate --split tune       # סט הבדיקות: נכונות, Recall, MRR, זמנים
```
