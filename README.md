# בוט RAG למלון צוף הכרמל

בוט שעונה על שאלות של אורחים על מלון בחיפה: חדרים, מה יש בכל חדר, מחירים, מתקנים ונהלים.
הבוט עונה רק לפי המידע במאגר ומציג את הקבצים שהתשובה מבוססת עליהם.
**המלון וכל הנתונים בדויים.**

## התקנה והרצה (PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env; notepad .env   # להכניס OPENAI_API_KEY
python ingest.py                            # בניית האינדקס (בכל שינוי ב-data/)
streamlit run app.py
```

## ארכיטקטורה ובחירות טכנולוגיות
`data/*.md` → `ingest.py` (טעינה, חלוקה, Embeddings, Chroma) → `app.py` (חיפוש, תשובה, מקורות, ממשק).

- **LlamaIndex:** רכיבים מוכנים לכל שלב (`SimpleDirectoryReader`, `SentenceSplitter`, `VectorStoreIndex`), בלי לכתוב אותם לבד.
- **Chroma מקומי (cosine):** מאגר וקטורים שנשמר בתיקייה, בלי שרת ובלי חשבון.
- **`text-embedding-3-small`:** זול ומהיר, ותומך בעברית.
- **`gpt-4o-mini`, `temperature=0`:** מהיר וזול, ותשובות עקביות בלי "יצירתיות". אפשר להחליף את שני המודלים דרך `.env` (`LLM_MODEL`, `EMBED_MODEL`).
- **`CHUNK_SIZE=1024`, `TOP_K=4`:** כל קובץ חדר נשאר קטע אחד, והמאגר קטן (15 קטעים).
- **חיפוש כפול:** חיפוש על השאלה לבד, ועוד חיפוש על השאלה והתשובה הקודמות יחד עם השאלה, כדי ששאלות המשך יימצאו.
- **Streamlit עם Streaming:** ממשק צ'אט קצר בקוד, והתשובה מופיעה תוך כדי כתיבה.
- **truststore:** בלעדיו החיבור ל-OpenAI נכשל מאחורי סינון אינטרנט (נטפרי).

## בעיות ותיקונים
הפירוט המלא ב-[docs/problems.md](docs/problems.md).
1. **בעיה:** קטעים של חדר בלי שם החדר, והתשובות ערבבו פרטים בין חדרים. **תיקון:** הגדלת ה-Chunk, כך שכל חדר הוא קטע אחד.
2. **בעיה:** השאלה הקודמת הסיטה את החיפוש לנושא הקודם. **תיקון:** חיפוש גם על השאלה הנוכחית לבד, ואיחוד התוצאות.
3. **בעיה:** בשאלות על "כל החדרים" נשלפו חדרים באקראי, ופעם אחת הומצא מחיר. **תיקון:** קובץ סיכום של כל החדרים, וכלל בפרומפט שכל מספר חייב להופיע בקטעים.
4. **בעיה:** שאלת המשך ("וכמה זה עולה?") לא מצאה את החדר שהוזכר רק בתשובה הקודמת. **תיקון:** חיפוש ההמשך כולל גם את התשובה הקודמת.
5. **בעיה:** המודל זרק מידע חלקי, והניח עונה מתוך ההיסטוריה. **תיקון:** כללים מפורשים בפרומפט.

הפיתוח נעשה בעזרת Claude Code.
