# בוט RAG למלון צוף הכרמל

בוט שעונה על שאלות של אורחים על מלון בחיפה: חדרים, מחירים ועונות, אוכל, שבת, משפחות, שירותים, נגישות, הנחות ונהלים.
הבוט עונה רק לפי המידע במאגר ומציג את הקבצים שהתשובה מבוססת עליהם.
**המלון וכל הנתונים בדויים.**

## התקנה והרצה (PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env; notepad .env   # להכניס OPENAI_API_KEY
python ingest.py                            # בניית האינדקס (בכל שינוי ב-data/)
streamlit run app.py
```

## ארכיטקטורה ובחירות טכנולוגיות
`data/*.md` → `ingest.py` (טעינה, חלוקה, Embeddings, Chroma) → `app.py` (חיפוש, תשובה, מקורות, ממשק).

- **LlamaIndex:** רכיבים מוכנים לכל שלב (`SimpleDirectoryReader`, `SentenceSplitter`, `VectorStoreIndex`), בלי לכתוב אותם לבד.
- **Chroma מקומי (cosine):** מאגר וקטורים שנשמר בתיקייה, בלי שרת ובלי חשבון.
- **`text-embedding-3-small`:** זול ומהיר, ותומך בעברית.
- **`gpt-4o-mini`, `temperature=0`:** מהיר וזול, ותשובות עקביות בלי "יצירתיות". אפשר להחליף את שני המודלים דרך `.env` (`LLM_MODEL`, `EMBED_MODEL`).
- **קובץ לכל נושא, `CHUNK_SIZE=1024`:** 27 קבצים קצרים (חדר, עונות, אוכל, שבת, חניה וכו'), וכל קובץ הוא קטע אחד. כך קטע לא מתפצל באמצע נושא.
- **`TOP_K=6`:** מספיק כדי לשלוף את החדר וגם את הנוהל הקשור, מתוך 27 קטעים.
- **ניסוח מחדש של שאלות המשך:** קריאה אחת ל-LLM הופכת "כמה הוא עולה?" לשאלה עצמאית לפי 6 ההודעות האחרונות. השאלה המנוסחת משמשת לחיפוש ולתשובה, כך שה-LLM שעונה לא צריך את ההיסטוריה.
- **Streamlit עם Streaming:** ממשק צ'אט קצר בקוד, והתשובה מופיעה תוך כדי כתיבה.
- **truststore:** בלעדיו החיבור ל-OpenAI נכשל מאחורי סינון אינטרנט (נטפרי).

## בעיות ותיקונים

1. **בעיה:** חדר התפצל לכמה קטעים, ושם החדר הופיע רק בראשון, ולכן התשובות ערבבו פרטים בין חדרים.
   **תיקון:** קטע גדול יותר, כך שכל חדר הוא קטע אחד.

2. **בעיה:** בשאלות על "כל החדרים" נשלפו חדרים באקראי, והמודל המציא מחיר.
   **תיקון:** קובץ סיכום של כל החדרים, וכלל בפרומפט שכל מספר בתשובה חייב להופיע במידע.

3. **בעיה:** שאלות המשך ("וכמה הוא עולה?") לא הבינו למה הן מתייחסות.
   **תיקון:** ניסוח מחדש של שאלת ההמשך לשאלה עצמאית לפני החיפוש.

4. **בעיה:** כשבמידע כתוב "אין מיני-בר", המודל ענה "לא מצאתי".
   **תיקון:** כלל בפרומפט ש"אין" ו"אסור" הם תשובה.
