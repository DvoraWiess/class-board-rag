# שאלות בדיקה

השאלות הורצו ברצף כשיחה אחת דרך `retrieve_documents()` ו-`generate_answer()` מתוך `app.py`,
אחרי כל התיקונים (ראו [docs/problems.md](../docs/problems.md)). התשובות מועתקות כמו שהן.
המקורות הם שמות הקבצים שנשלפו (TOP_K=4 לכל חיפוש, ובשאלה שאינה הראשונה יש גם חיפוש המשך).
