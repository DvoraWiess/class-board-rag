# SAMPLE DATA — נתוני דוגמה בלבד

ההודעות בתיקייה הזו **מומצאות**. הן ההודעות ההתחלתיות של לוח ההודעות, ומשמשות לפיתוח ולבדיקות.
כשהאפליקציה עולה ו-`data/emails/` ריקה — הן מועתקות לשם. נוצרות מחדש עם `python -m tests.make_sample_emails`.

הקבוצה: שיחה בין תלמידות בלבד (כיתה י'2, "בית ספר לדוגמה"). אין הודעות רשמיות —
התלמידות מעבירות מידע ("המורה אמרה ש..."), שואלות ועונות.

סימנים מזהים:
- `message_id` בתבנית `<sample-NN@sample.test>`
- כתובות בדומיין `example.com` (דומיין שמור לדוגמאות), שמות בדויים
